# 量化观察与原策略衔接

这里量化的是**公开可观察变化**，不推断谁在买。以下参数是首版可调整研究默认值，未经收益验证，不是用户既有买卖门槛。

## 1. 数据与状态

事件记录至少有id、类型、标题、primary_source、published_at、known_at、scheduled_at/occurred_at、时区、修订记录、实际取得时间、事实/推断/假设、受益链和失效条件。known_at为该版本最早可核验公开时点，不能早于源发布；只有日期无时间的盘中消息，按无法确认当时已知处理。可预排日历和当期结果各建版本；日程已知不等于结果已知。

每个输出保留market_as_of、information_as_of、generated_at；历史研究按信息截止过滤，不使用后续修订、更晚财报或现存成分倒填历史。公司公告风险未核验时不能升级买入研究，重要缺口简短说明。

阶段只有：日历观察、事件已确认/等待盘面、条件式观察、已兑现/失效、资料不足、历史研究。事件研究自身不生成eligible=true；原生策略的观察/入场/退出状态原样并列，不合成多数票。

## 2. 同口径比较

默认市场基准沪深300；另看已核验主板广度。行业/概念供应商及代码固定，同花顺和东财不偷偷混排。成分先排除不符范围的证券再冻结，展示原数/剔除/合格/有数据数；少数样本只能说明局部，缺少必要成分不得声称整板块确认。不足三只有效股票不评估板块扩散。

价格收益使用同截面一致复权收盘；实际涨停另用未复权价及当日涨停价。板块默认研究组合，不冒充供应商指数：以信号日开始前冻结的合格成分，逐日等权收益链接计算区间收益；窗口内不得按涨幅选入/删除成分。停牌股票用明确的零交易/参考收盘规则，不把缺失默认为停牌。历史池无法还原则不能称可交易回测。

| 观察项 | 明确定义 | 首版提示，不是单独买点 |
| --- | --- | --- |
| RS3/RS5 | 组合3/5交易日累计收益减同期沪深300累计收益，单位百分点 | RS3>0表示短期相对强；正相对收益仍可绝对亏损 |
| 相对强度加速 | 最近3日RS3减之前不重叠3日RS3 | >0说明改善，不能据此证明持续 |
| MA20广度 | 同一完整合格成分池中，最新收盘≥各自MA20的比例 | ≥50%且较3交易日前上升，才提示扩散；未知不能压缩分母提高比例 |
| 板块成交支持 | 最近3日板块每日实际成交额均值÷紧邻此前20日均值，即[D−2,D]比[D−22,D−3] | ≥1.2仅作活跃提示；需23日真实成交额，不估算close×volume |
| 价格所处位置 | 个股r5/r20、距最近压力/冻结支撑、ATR或原策略位置 | 区分待启动、已突破、加速；不以低价/跌幅认定便宜 |
| 事件预期差 | 实际结果与发布前留档的同口径预期 | 无事前预期则不计算“超预期”；净利需区分扣非和一次性 |
| 拥挤与承接 | 最大个股/前三成交额占比、涨跌扩散、炸板反馈、长上影、后续量价 | 个股独涨和成交集中时，不能用板块总量替全板块背书 |

研究默认提示可帮助排定“先复核谁”，不能绕过原Skill条件，也不把涨幅、换手、量比等相关指标当独立的三份胜率证明。不创建加权总分或宣布量化资金流入。

资金测算只能列假设：调整后的ETF份额变化×相应单位净值可估算申赎净额，但需处理份额折算、分红与日期错配，实物申购不等于当日同额新增买股。可核验被动跟踪规模×权重变化只是指数调仓需求情景，不把指数增强规模当完全复制，不重复计ETF和其联接基金；没有执行证据不写已流入。解禁数、计划减持上限、回购上限均不是实际成交量。

盘中比较使用相同交易分钟/同一池的历史同刻量额，排除午休。不能以14:00累计量比昨天全天，不能把日线3/20提示值搬到分钟。最终竞价、分钟VWAP、同刻量分别用原生证据；实时判断默认源数据延迟≤90秒、跨报价差≤60秒，超过就只复盘。请求时间不能替代源时间，不能借股价时间给资金字段更新时间。

## 3. 实际选择原Skill

启动前潜伏的固定来源为 [a-share-prelaunch-stock-skill V3.4](https://github.com/Mrrabbitan/a-share-prelaunch-stock-skill/tree/21f0fa43c160e36f8fdfbe40d1ebabd652c16b80)，提交21f0fa43c160e36f8fdfbe40d1ebabd652c16b80。在现有工作台先核对docs/playbooks/registry.json的prelaunch条目和对应固定原文；独立使用时从上述固定提交读取SKILL.md及引用文件，不自动替换成仓库最新分支。无法取得固定原文/计算器时标为未执行，不依赖本表简述复刻算法。其余四项按会话可用技能目录的同名Skill定位；不可用者同样不假称执行。

| 形态与目标 | 使用哪项 | 必须保留的边界 |
| --- | --- | --- |
| 真正未加速、试盘后缩量承接 | 固定来源的启动前潜伏V3.4 | 最近压力、含费用空间、冻结支撑、五交易日期限；没有安装时不得自编原Skill |
| 首板、一进二/二进三、首板后守位 | a-share-yichujifa | 三分支和原行业前三；冰点阶段、9:50后新事件、两次至少60秒的确认 |
| 热点核心连板分歧回封 | a-share-dragon-cycle | 热点原排名、昨日资格、9:25最终竞价、真实回封与第二次放量退出；新闻不加原评分 |
| 尾盘强势隔夜 | a-share-late-day | 当时完整分钟证据、原时间/七条件/否决、次日10:00纪律；收盘数据不倒推尾盘可买 |
| 三日温和上涨、活跃和历史股性 | a-share-three-step | 全主板换手排名、同日模型获利筹码、60日实际收盘封板；仅收盘观察 |

不是每个事件都需要跑五项。先依形态选适用者，用户要求全校验才逐项执行；不适用、未执行、缺证据、失败和通过分别保留。一项完整通过可独立支持它自己的观察结论，不能抵消证券硬风险或同一策略已经触发的退出。

例如主题首板可列一进二观察，但不能称已满足龙空龙昨日至少两板资格，也不能当启动前潜伏。事件加成不能把原板内第四名提升成前三；也不能新增到现有尾盘14:00冻结池或龙空龙资金监测。

## 4. 介入研究与退出

值得进一步介入研究，至少要同时说明：证据何时已知、公司为什么相关、市场承接如何、当前价格还有什么空间、原策略哪一项完整成立、何种表现推翻判断。若只有主题注意力而无利润证据，明确属于短线主题交易，不给半年持有结论。

常见撤销观察：日程取消/明显延期、力度低于事前预期、公司澄清无业务关联、实际订单/利润不兑现、冲过压力后放量跌回且承接失败、板块退潮。价格触发必须按对应原策略、冻结线和当时证据表述，不自行添加通用止损百分比。

事件后1—5交易日是复核窗口，不是强制持有或统一到期卖出。存量持仓的退出优先于新观察；T+1、停牌、跌停和无对手盘造成的阻碍必须保留，不按理论价记录成交。

## 5. 私有研究记录

保存本次日期/时点、事件版本、来源链接与取得时间、成分日期、原生策略版本/指纹/覆盖、计算输入/结果、未执行原因、结论和有效期。相同证据重复读取不新造事件；变更保留旧版，已过时不重标当前。没有数据的方向保留简短阻断，不能用虚构示例替换实际研究。公共仓库不放真实名单、行情、研究或账户；本Skill本身不授权外发。
