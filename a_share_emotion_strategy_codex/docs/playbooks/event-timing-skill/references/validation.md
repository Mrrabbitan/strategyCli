# 检验“某个时间总会涨”

## 1. 先登记假设，后看结果

例：中秋前若两岸主题存在异常收益，是否显著高于同期市场及相近规模/行业股票？是否仍能覆盖交易费用？例子是待研究命题，不是已发现规律。

事前固定：事件定义、当年交易日历、首次可知时间、事件发生时间、主板范围和当期成分、参数、样本起止、持有期、对照和可成交规则。保留失败年份、没涨的成分及失效事件。不能只挑被热议年份或本轮涨停股；同一公司跨概念不制造多个独立样本。

对节日可先登记[-20,-6]、[-5,-1]、[0,+1]、[+2,+5]交易日观察段；T=节日后首个交易日，节前最后一个交易日为T−1。对公告，另以A=首个可交易时点对齐，不混为同一个T。窗口只是初始研究参数，不能事后选最赚钱段作为唯一结果。已知节日前瞻与公告后交易是两个不同策略。

## 2. 收益与风险口径

- 同时报告绝对收益、超额收益、最大回撤、盈利/亏损分布、样本量与置信范围；不能用“跑赢下跌大盘”代替正收益。
- 交易信号在收盘确认，收益从之后实际可交易价格开始；公告盘后披露也不能用该日收盘买入。分钟证据不足就只做事件研究，不报可执行交易收益。
- 总回报和价格回报分开，计入分红/除权，涨停核验仍用未复权价。实际买卖计佣金、印花税等适用费用、滑点和冲击；每次使用当时适用费率。
- A股T+1、停牌、一字板排队、跌停卖不出、成交容量、假期跳空都进入可成交假设。禁止假设涨停价随意成交或日内任意反向平仓。
- 基准、成分及行业分类必须当期可知。退市、ST和上市不足历史的股票按当时规则处理，不能用今天的合格池回填过去。
- 年度节日每年才一次独立事件，即便含多只股票也不是许多独立年份。控制同日和同板块相关性，区分样本内、留出年份和走样本外检验。
- 同时试多个节日、窗口、行业和参数需处理多重检验与数据挖掘偏差。分牛熊/震荡、政策增量有无、提前涨幅等状态检验；报告策略在哪些场景失效。

历史通过不保证未来有效；规则格式校验、离线算例和回测收益是三件不同的事。无样本或无费用只能写“未经验证”，不能给编造胜率、主升浪概率或量化入场日。

## 3. 行为校验用例（全为虚构）

| 输入情景 | 应有输出 |
| --- | --- |
| 假期将近，仅论坛称区域股必涨，没有公告/联动 | 日历观察或不做；不能称机构布局 |
| 官方活动确实举行，但只为文化联谊，公司无关联 | 只证明活动，不能升级业绩受益或交易资格 |
| 18:00公告超出可核验旧预期，输入要求15:00已入场 | 截断未来信息，公告后下一可交易时点才可能复核 |
| 同板块只龙头上涨，其他成分缺数据 | 不能确认板块扩散；局部证据不冒充全池 |
| 当日涨停、相关度高，原热点排名第四 | 不挤进龙空龙/一触即发限定前三；主题列表不改原排名 |
| 价格突破但原龙空龙累计第二次放量 | 保留原退出风险，不能用事件覆盖退出 |
| 公告净利增长高但扣非下降、经营现金流转弱 | 下调基本面判断，不能等同订单盈利兑现 |
| 15:00日线漂亮，缺14:30分钟及VWAP | 尾盘历史证据不足，不倒推尾盘已通过 |
| ETF成交活跃但份额没增长或缺失 | 不能写净申购/真实资金净流入 |
| 最后成功报告是过去时点，本次接口失败 | 最新尝试失败并列旧结果，旧结果仍是历史 |
| 报价过期，给出新请求时间 | 不补行情时间戳，不输出实时满足 |
| 提到“中秋前布局”，没有要求定时任务 | 只按需研究，不创建或恢复任何监控 |

自检重点是时点、证据链、独立规则和失败边界；不要求为了完成一份分类总结而重新跑全市场。
