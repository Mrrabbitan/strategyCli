# 可提前研究的事件与触发窗口

这是一份机制目录，不是收益日历。下表的方向是**待核验映射**，不表示该方向一定受益；公司需有真实业务、收入/成本敞口或明确资金约束。所有提前期都是研究排期，不能直接当买入日期。

## 1. 按事件阶段安排工作

以T为事件计划发生时点；同时保存首次公告A。T可能延期，A不能用新闻转载日期替换。

| 窗口 | 做什么 | 何时才值得进一步参与研究 |
| --- | --- | --- |
| 公开日历已知、尚无增量 | 建事件台账；节日/会议前约5—20个交易日开始查证 | 仅日历观察，不提前认定资金介入 |
| 首次具体公告/预期修正 | 核政策力度、实际订单、收益归属，冻结原始受益池 | 关联真实且不是旧闻；未过度提前上涨；原策略资格另核 |
| 公告后的首个可交易窗口 | 看实际成交、板块联动、是否冲高回落 | 盘中须用新报价/分钟证据；不能拿公告当日全天收盘倒算买点 |
| 首次放量后分歧/回踩 | 比较缩量承接与此前冻结支撑，不追随意“回调就是洗盘” | 适配原策略，承接未失效；重上关键位或回封有顺序证据 |
| 落地后1—5交易日 | 检查兑现、业绩修正及板块扩散是否继续 | 没新增证据就到期复核，不因涨了再移动期限 |
| 取消、效果不及原预期、量价反向 | 下调/移出事件观察；持仓按原策略管理风险 | 不用新叙事掩盖失效；退出受T+1和流动性限制 |

## 2. 全年可预排的注意力窗口

不是固定日期或买入月份；以当年官方日历、主办方及公司披露为准。

| 常见时段/事件 | 可研究的方向 | 必须看到的增量 | 常见误判 |
| --- | --- | --- | --- |
| 春节、春运、返乡 | 航空机场、铁路公路、旅游酒店、食品、影视 | 预订/客流/票价/票房与利润率，成本和容量约束 | 客流高就利润高；放假前一定涨 |
| 3月政策会议与年度预算 | 设备更新、基建、消费、能源及科技等实际获支持方向 | 正式政策对象、资金来源、落实时间、可中标主体 | 把会议热词当确定订单；年年同一行业获益 |
| 春耕、灌溉与农资备货 | 种业、农机、化肥、农药、水利 | 农产品收益、招标交付、库存与价格变化 | 农时固定便等于农业股固定上涨 |
| 年报/一季报密集期 | 盈利改善和现金流兑现公司 | 正式预约/预告、扣非与经营现金流、事前预期 | 把低基数高增长、一次性处置当持续增长 |
| 五一、暑期、国庆长假 | 出行、酒店、免税零售、影视等 | 预订向实际销售/利润转化，剔除旺季已被定价 | 临放假追已涨很久的龙头；忽略长假外部风险 |
| 618、双11、年货促销 | 电商、物流、包装及有真实品牌销售的公司 | 扣退货后销售、利润、履约成本 | GMV、快递件量增长等于利润增长 |
| 夏季用电/汛期；冬季取暖 | 发电、电网、煤气、制冷；部分防汛设备 | 实际天气/负荷/调度、煤气成本、合同价、订单 | 高温利好所有电力；灾害自动利好所有水利 |
| 中报/三季报密集期 | 当季订单和利润兑现方向 | 同口径环比/同比、在手订单交付、应收与现金流 | 传闻业绩、研报估值代替披露事实 |
| 中秋与两岸交流、海峡论坛、区域会议 | 两岸业务、交通物流、旅游与有项目实益的企业；纯区域标签另列 | 国台办/当地政府新措施、项目/航线变化及公司业务证据 | 团圆寓意=股票利好；地名=收益；量化必然扫板 |
| 消费电子新品、科技开发者大会、车展、航展 | 经核实供应链、设备材料、汽车、相关制造 | 发布内容相比预期的变化，订单、ASP、量产与份额 | 展示原型/送样/认证=批量订单；蹭概念 |
| 四季度预算执行、来年资本开支与订货会 | 有正式招标和交付的设备、工程、软件等 | 资金到账、合同执行、收入确认与回款 | 冲量和项目总投资额都算当年营收 |
| 年末经济政策会议、次年规划 | 新增政策覆盖方向 | 正式文件与后续可执行措施 | 年末必有跨年妖股，预先认定某只将成龙头 |
| 月末、季末、半年末、年末、长假前后 | 全市场流动性与风格暴露 | 资金利率、融资和实际成交等可验证变化 | 调仓/排名/节后回流一律当作上涨保证 |

## 3. 不定时或单次事件

| 类别 | 可研究方向与机制 | 有效观察节点 | 反证与避让 |
| --- | --- | --- | --- |
| 降准、政策利率/LPR、信贷与财政安排 | 融资成本、信用和需求影响不同，银行息差也可能受压 | 官方发布→首个交易窗口→信用/需求落地 | “宽松”不等于全部盈利上升；日期/幅度未经公布不能写成确定 |
| PMI、CPI/PPI、社融、进出口、工业/消费数据 | 需求、库存和利润预期修正 | 统计局/央行/海关发布时间，和事前一致预期比较 | 同比受基数影响，数据利好可能早已定价 |
| 美联储与海外宏观、汇率、利率 | 外币收入、原材料进口、美元债务、折现率 | 转上海时间，对齐A股下一可交易时点 | 贬值不普遍利好出口；海外利好遇国内退潮仍可跌 |
| 产业扶持、集采、反垄断、环保、出口限制 | 受益/受损两面；替代空间与下游成本 | 政策原文、征求意见到落地的差异 | 征求意见=生效；国产替代口号=已取得份额 |
| 大单、中标、产能投放、订单上修 | 收入与利润能见度 | 合同金额/执行期占收入比例、毛利、客户集中和付款条件 | 框架无约束、重复统计订单、投产即满产、将保密传闻当事实 |
| 产品涨价、成本下降、去库存/补库存 | 毛利、产销、库存计价 | 产品/原料价差而非单边报价；成交价/销量和利用率 | 上游涨价伤害下游；缺成交的报价不是已实现利润 |
| 资产重组、收购、控制权变化、资产出售 | 估值/盈利主体改变 | 正式方案→审核→交割，各阶段独立核验 | 失败、摊薄、商誉、关联交易；停牌期并不可买 |
| 回购、增持、特别分红、股权激励 | 资本配置及供求约束 | 董事会预案、批准、实施与完成分别记录 | 回购预案等于执行；分红除息后凭空增加收益；激励必达业绩 |
| 解禁、减持、再融资、可转债转股 | 潜在供给、筹资成本与稀释 | 解禁/计划/实际实施分开；比较可流通规模与成交能力 | 解禁必砸、减持计划等于已卖；反过来也不能一律看成利空出尽 |
| 指数调样、权重调整与被动跟踪 | 可估计的跟踪需求/供给 | 公告日和生效日分开，核对跟踪资产与原持仓 | 调入必涨；生效收盘已拥挤；将指数预测名单当官方名单 |
| ETF份额变化、互联互通资格变化 | 可能的股票篮子需求与交易可及性 | 原生份额、申赎清单、实际时间和有效日期 | 二级成交额等于净申购；份额增长直接等于同额买股 |
| 期货/期权到期、基差与套保迁移 | 可能的对冲/展期需求 | 对应合约条款、实际基差/持仓变化 | 到期日一定跌；散户能无成本复制机构套利；名义持仓直接当买盘 |
| 海外龙头财报、行业资本开支 | 国内供应链订单修正 | 海外公告时点与公司关系、产品份额/量产、后续订单 | 海外上涨=国内概念股都受益；隔夜消息用前日收盘成交 |
| 地缘、天气、事故、疫病等突发 | 供应链、避险、需求与成本冲击 | 官方确认之后评估直接暴露和反向成本 | 传闻抢跑；事件严重就相关股必涨；事件不可提前知道 |
| 监管风险、审计异常、重大诉讼等 | 通常先做风险排除 | 官方公告披露后更新资格 | 为保留主题故事忽略硬风险；反弹即风险解除 |

## 4. 盘面触发，不依赖固定日期

| 状态 | 有意义的介入研究节点 | 不足以成立的情况 |
| --- | --- | --- |
| 趋势启动/突破 | 板块相对强度与广度改善、个股突破最近压力后仍有承接 | 单只拉升；成交额放大但长上影；已经远离支撑仍称低位 |
| 主线首次分歧再修复 | 固定龙头和板块恢复，新回封/突破有当时证据 | 缩量一概当洗盘；重复旧封板截图 |
| 情绪冰点后修复 | 晋级、炸板、跌停与最近多板阶段同时改善，按原一触即发确认 | 跌多了必反弹；仅指数红、接力继续崩 |
| 强板块回踩/均值回归 | 结构未失效、公司逻辑未恶化、费用后空间足够 | 便宜等于反转；把下跌趋势当正常回踩 |
| 高低切换/补涨 | 原主线仍有效、低位公司有独立业务关联和新成交支持 | 龙头退潮时硬买后排；凭“没涨”认定会补涨 |
| 避险/风格切换 | 防守方向相对强、现金流与估值条件合适 | 只跑赢下跌大盘却称能获正收益 |
| 拥挤与兑现 | 放量滞涨、领涨集中、强股补跌或事件落地后不涨 | 越放量越好；长假/周五无条件卖出或买入 |

## 5. 日内时段的职责

盘前做事件查证和昨日资格；9:25后才可读最终竞价成交；开盘后看真实换手承接。9:50门槛仅属于一触即发，14:00/14:20仅是既有尾盘预观察，14:30≤t<14:57仅属于尾盘隔夜新增窗口。14:57之后不能冒充连续竞价研究。午后拉升不是量化身份标记，任何时刻都先执行已触发的风险退出纪律；普通A股T+1与可能无法成交的限制仍适用。不要为本技能另外创造统一最佳分钟。
