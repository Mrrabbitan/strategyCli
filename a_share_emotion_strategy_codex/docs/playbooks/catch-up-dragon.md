# 主线扩散补涨龙 v1.0.0

目的：龙头无法成交时，只研究同一主线内开始独立转强的跟随股；不能因买不到而被迫降低标准。

顺序：市场支持 → 龙头仍强且至少两只其他相关股扩散 → 主营/催化一致 → 同日期涨幅落后且未加速 → 完成日线MACD → 自身突破后站稳 → 成交可行性与失效复核。

首版默认：冻结T0，同区间落后龙头至少5个百分点；近5市场交易日涨幅>0且≤15%，收盘≥MA20，连续板数0或1。MACD12/26/9用至少130根完成日K，DIF≥0、DIF≥DEA、柱值>0。它们只是可调整研究门槛，不证明上涨概率。

确认线为当天之前10个完整交易日最高价，不是最近压力。突破后至少两根完整5分钟K站上确认线，第二根最低价不低于它，龙头/板块未转弱，再判断可执行性。日量与此前5日均量默认1.2—2.5倍；盘中只比历史同刻量。更近阻力、滑点及涨停买不到不能忽略。

结构、主线失效优先风险处理，不等MACD死叉。新买入当天不能卖，下一交易日跌停可能退出受阻。没有成本/日期只给情景退出，不认定持仓。

龙空龙继续独立按原排名、回封及第二次放量规则运行；补涨池不覆盖热点原榜，不继承龙空龙资格。其他已暂停策略不参与筛选、评分或推荐。
