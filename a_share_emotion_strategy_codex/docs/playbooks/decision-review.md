# 持仓、自选与研究名单的三梯队复核

本流程用于用户明确要求的局部名单比较。它不修改三套策略的参数，不产生自动交易授权，也不替代各策略独立核验。

## 数据与范围

- 按证券代码合并持仓、自选和此前研究，保留来源、截图时间与原始比较池。截图未显示日期时明确未知；与旧记录相同不能证明当前账户未变化。
- 行情截止、信息取得、计算时间和观察到期分别记录。账户数量仅使用用户确认的快照，不用最新价格反推实际资产或假定建议已成交。
- 当前价交叉核验不等于历史复权、公告和行业广度全部通过。旧经营数据、资金分类和旧名次保留原日期，不能包装成当日证据。

## 三梯队与排序

1. **条件可操作**：只有对应策略的完整收盘预资格通过，才可列待次日确认；实际竞价、回封或突破尚未出现时不能称为可买。没有合格项则为空。
2. **观察**：分别说明现有持仓修复、待启动研究、已启动跟踪及缺证据状态。研究复核顺序可以变化，但板内原始前三不因此重排或递补。
3. **退出／排除**：持仓项区分已触发失效与条件减险；未确认持有的股票只能移出新增候选，不能写成卖出指令。未知持仓状态不得强行标为未持仓。

优先检查已触发失效、承接恶化和同产业集中风险，再检查新增资格。持仓集中度只是风险背景，不单独生成固定减仓比例。买入所用策略及持有周期未确认时，不把另一策略的门槛套成强制卖出规则。

## 晋级与降级

- 每次变化写明新证据、最强反证、确认条件和失效条件；没有新增证据不续期旧交易资格。
- 龙空龙按首板起逐日放量账本核验，缩量和换日不清零；普通趋势股日常放量不能冒充连板周期第二次放量。
- 一触即发独立检查分支、首板锚点、冰点修复及盘中事件。另一策略排除不等于本策略硬失效，另一策略观察也不能借来放行。
- 潜伏保留冻结结构、已启动和失效记录。回调、五日涨幅下降或均线改善不自动重建潜伏资格。
- 数据任务失败时显示失败及历史快照到期，不将旧观察池恢复为当前信号，也不把失败描述成成功筛得零只。

## 发布与隐私

实际账户、名单、价格及排名只写私有专题，通过 `publish_topic()` 和统一构建更新页面；用 `related_modules` 将专题链接到四个研究模块，保持六个主入口。

公开 GitHub 仅同步本流程等可复用规则或通用代码。提交使用逐文件白名单，不包含截图、实际持仓、私有研究和行情快照。完成时分别报告页面行情时点、验证结果及代码提交推送状态。
