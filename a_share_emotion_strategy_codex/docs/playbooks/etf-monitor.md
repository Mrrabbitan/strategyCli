# ETF监控视图

这是公共市场的只读研究视图。热度、上涨趋势、反转阶段及适合参与分别判断，不用未经验证的加权总分或概率替代证据。独立入口为`#page-etf-monitor`，当前工作台共十一个入口，保留高标异动与其他现有模块及暂停配置。

用户最新要求移除同花顺资金模块：ETF普通资金卡片、独立“板块资金”导航及主页面中的旧资金专题均不再展示。保留东财20日模型主力历史和日K大阴线。三个ETF任务取消同花顺资金采集、解析及`import --flow`；旧私有原文和legacy工具只留档、不自动运行。该变化只限定资金模块，同花顺报价和行业指数等已授权行情来源不受影响。

## 独立东财主力历史榜（新增授权）

用户已明确批准东方财富模型主力资金历史。页内入口`#etf-em-history`，每天可选最近20个完整交易日，分别展示主力净流入与净流出前十及同源大单、超大单明细。日期选择、证据展开和阅读位置随页面版本更新保留；旧同花顺普通净额归档不参与当前榜单。

`etf_flow_history.py`独立采集与归档，公开行业目录通过官方分类选择器核验行业/概念/地域分组，冻结本轮行业池。目录取得时点不能补为历史分类生效时间；回溯只称本轮行业池的源生资金历史，不声称还原各历史时点的全市场行业全集。未核验成分互斥时，不加总各行业净额称市场总资金。

资金日线使用东财原生日期和人民币元单位。主力净额须等于大单加超大单，逐行检查原精度、代码名称、唯一有序日期、窗口与完整交易日。失败或缺行不填0；只有本轮完整行业池在该日全部核验后才出正式前十，否则显示覆盖不足。正净额降序为流入，负净额升序为流出，零净额不塞入任一榜。20日累计只使用全部20日完整且全池核验数据，不能用局部加总冒充完整累计。

```sh
python3 etf_flow_history.py collect --cutoff <最近完整交易日> --days 20 --build
```

实际目录、原响应、完整矩阵及结果仅保存到私有`research/etf_flow_history/`。首次补录是事后数据整理，不能倒填成当时已经发出的信号；供应商历史可能含修订，不证明当时可知。09:00和09:55优先读取相同截至日已完成快照，15:40出现新的完整交易日再滚动；不增加任务、不重复日内全池采集，历史模块不生成交易指令。源定义与单位依据[维护者字段映射](https://github.com/akfamily/akshare/blob/master/akshare/stock/flow/stock_fund_em.py)及[东财原站前端](https://data.eastmoney.com/newstatic/js/bkzj/detail.js)核验，不能把模型主力称为真实机构账户资金或ETF净申购。

## 数据与发布

采集保留原始响应、来源、取数时间和复权口径；独立离线适配器`etf_monitor.py`读取已经保存的证据，生成白名单字段快照。境内输入为收盘研究JSON与可选腾讯`qfqday`或明确`fqt=1`的东方财富原始证据，美股输入为已保存的调整后日线报告。腾讯请求参数为qfq但响应仅有day时，不将day静默当作前复权。所有真实文件使用私有存储，不作为源码示例。

```sh
python3 etf_monitor.py import --close <私有收盘研究.json> --cn-evidence <私有境内日线证据.json> --us <私有美股研究.json> --build
```

输出使用`research_path('etf_monitor/current.json')`及私有历史，构建使用既有`build_investment_site.py`。不增加网页执行接口、行情轮询或新扫描服务。构建器不访问市场网络。现有30秒版本检查只在数据发布后刷新页面，保留筛选、排序、展开项与阅读位置。

## 指标

- N日收益：最近完整收盘相对N个交易记录前收盘的涨跌幅，需要N+1条有效记录。缺历史不补值；未独立核对交易所日历的完整性另标缺口。
- MA20/60：同口径收盘算术均值；均线方向与5个交易记录前的自身均线比较。境内使用前复权收盘，美股使用调整后收盘；两者绝对价格不互比。
- 20日年化波动：20个日对数收益的样本标准差乘以`sqrt(252)`，以百分数显示；这是历史波动，不能保证未来损失。
- 60日窗口最大回撤：窗口内收盘相对此前滚动最高收盘的最大跌幅，保留负号；不称账户回撤。
- 美股RS20：同日期窗口的20日收益减SPY20日收益，单位为百分点。跑赢下跌市场不能单独称上涨趋势。境内未取得同口径沪深300基准时RS留空。

价格、均线、涨幅和动量均来自价格，不能当作多份独立确认。成交量/成交额不是净流入；ETF份额净申购不等同当日现金买股。

## 观察状态

中期上升要求价格在MA20之上、MA20高于MA60且较5个交易记录前抬升。初步拐点须先有下降结构，连续两个完整交易日站上各自MA20、近5日低点高于前5日且MA20不再下降；缺少任一字段只观察，不升级。其余反弹和均线下方结构分别显示修复或走弱。

页面列下一步确认与失效条件，不产生自动买入或清仓指令。事后收盘回补明确标记，不作为当时盘中可知信号。形态低点只作观察参考；未经事前冻结不称已记录的止损。长上影只提示抛压，其退出规则要单独验证。

## 完整日K压力

`etf_pressure.py`对已覆盖ETF代理的完整同源前复权OHLC检查大阴线：收盘低于开盘、开盘到收盘跌幅至少2%、实体占高低振幅至少60%、收盘处于高低区间下方25%。这是初始形态参数，未证明收益优势。昨收涨跌与实体涨跌分列，低开收阳不称大阴。放量为当日量/此前20个完整交易日均量，排除当日，达到1.2只作放量标记；缺量不否定完整OHLC已符合的形态。盘中、未来、日期错配或复权不明不确认，不能用未知充当“没有大阴”。

日线压力保存到`research_path('etf_pressure/current.json')`，只导入境内日线证据，不注入或展示旧同花顺资金字段。大阴线不单独推断“主力撤退”；形态为ETF代理而非行业全量扫描。没有符合者只说明已核验样本未见，另列当日跌幅较大样本，不强凑大阴名单。

```sh
python3 etf_pressure.py import --cn-evidence <私有境内日线证据.json> --build
```

## 热度、海外与政策

行业涨停榜按源提供的唯一行业分类统计，数量平手再比较这些涨停股的成交额；展示前8并标明完整池覆盖和10%/20%差异。该成交额不是整个行业成交额，不计算虚构净流入。不同供应商行业趋势只能作为近似参照，不能视为同一成分池的广度。

美股固定行业和子行业代理与SPY、QQQ分组观察。QQQ对应纳斯达克100，不能冒称纳斯达克综合指数。TAN等美国上市全球主题不等同美国本土行业。美国交易日与北京时间收盘时刻分别保存，跨市场映射只作推断，未经对齐历史不计算领先概率。

政策须有原文、阶段、最早可知时间、生效日和业务传导链；未完成核验时显示缺口，不能把空事件列表解释为没有政策风险。宏观利率、汇率、广度、估值、费用、份额和溢价缺失时不由价格代填。

## 时点与保护

沿用已授权ETF三任务：盘前09:00、盘中09:55、盘后15:40，休市按原规则跳过。三个任务均不采集、解析或导入同花顺资金。09:55必须另外保存真实分时复核，不用未完成日线升级反转；15:40只能引用最近已经结束的美股常规交易日。导入当前日线视图不代表两帧盘中条件已确认。

未来日期、源日期错配或无有效证据降级；超过4自然日仅历史参考，这只是保守的年龄提示，不替代交易日历或数据新鲜度核验。不按未知数据凑足榜单、补造无风险结论或推算个人仓位。实际研究和运行状态不进Git；源码与规则测试后按项目白名单推送。
