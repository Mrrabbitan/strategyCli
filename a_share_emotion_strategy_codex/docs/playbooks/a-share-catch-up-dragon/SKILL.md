# 主线扩散补涨龙 · v1.0.0

找到同一主线中开始独立走强的跟随股。龙头买不到不是必须交易的理由；缺扩散、可执行价格或证据时，空仓也是结果。首版没有收益或胜率验证。

## 执行顺序

1. 读 `references/rules.md` 与 `references/data.md`。接受分析时点、候选范围、原始资料、可选持仓记录，默认上海时区。核验最近完整交易日和研究阶段，不用周末/盘后资料冒充盘中信号。
2. 工作台执行前读项目 `AGENTS.md` 和 `strategy_policy.py` 的 `policy_status('catch-up-dragon')`；暂停则停止新增选股，只阅读历史。只用龙空龙和MACD作为独立参照，不借用已暂停策略的结论、阈值或评分。热点与板块雷达只提供行情背景，不恢复定时任务。
3. 联网核验日历、证券状态、市场量能、涨跌/封板表现、主线与公告。冻结龙头、主线、比较池、起始日T0和来源。原热点名次不被新榜重排。
4. 核验龙头以外是否扩散，以及候选主营是否直接相关。只做涨幅落后、未加速且自身转强的观察股，不用低股价、小市值或概念标签代替。
5. 用 `scripts/analyze.py` 计算核验后的日K。MACD为12/26/9，首收盘价初始化EMA，柱值为 `2×(DIF−DEA)`；至少130根有效完成K才确认。脚本只计算指标，不抓行情、不授予交易资格。
6. 收盘筛选只形成观察名单。盘中突破后站稳、同刻量能支持、龙头及板块未转弱，才给条件式介入；可买到与否另查，绝不虚构成交。
7. 分开记录事实、推断和策略默认值。实际研究按私有存储、更新锁和原子发布进入时点报告，再构建页面；源码/规则变化按项目约定提交，行情和名单不提交Git。

## 决策层次

- **盘面线索**：覆盖或来源不足，只说明看见什么，不发布正式主线排名。
- **收盘观察**：市场、主线、证券、主营、未加速和完成日线动能已核验，不等于可以买。
- **条件式介入**：观察项满足独立盘中承接要求，证据未过期，没有风险否决；仍不保证成交或次日上涨。
- **等待／取消候选**：主线失败、个股冲高回落、结构破坏或缺关键证据。不以“它还没补涨”保留资格。
- **持仓风险复核**：只有实际买入记录才讨论成本和盈亏。T+1与封死跌停可能使计划退出受阻。

## 输出

中文报告先给盘面结论和是否值得承担风险，再给最多3个方向、每方向最多3只已核验观察股；不足不补齐，其余记录私有留档。每股给：

- 龙头/主线关系、主营依据、冻结T0同区间涨幅差及“补涨而非弱股”的理由；
- 价量时点、10日突破确认线、已知更近阻力、MACD完成日线结果；
- 盘中确认、失效和退出条件、成交可行性、来源与关键风险。

未核验数据用一句必要说明，不堆流程清单。这是研究顺序，不是上涨概率排名；涨幅差不是目标涨幅。资金分类、龙虎榜和营业部不能证明真实游资接力，不能声称取得同花顺暗盘数据。

`python3 scripts/analyze.py INPUT.json`（`-`读取stdin）只计算核验后的日K，输入契约见数据参考。保留源日期、单位、复权和指纹；过去研究先截断未来，不用当前成分或公告补造历史。
