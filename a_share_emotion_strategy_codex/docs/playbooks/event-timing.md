# 事件与资金介入时机 · 1.0.0

独立技能：`a-share-event-timing`。自然语言询问“节前该研究什么”“未来有哪些催化”“板块什么时候值得关注”，或显式使用 `$a-share-event-timing`。

这是事件与量价的研究辅助，回答“提前看什么、何时证据足够、什么时候应放弃”，不预测真实量化账户。五种原选股策略、九个入口和原定时任务不变；不新增自动下单、预算或统一买卖算法。

## 主要窗口

| 类型 | 提前研究什么 | 升级关注的依据 | 避免的误判 |
| --- | --- | --- | --- |
| 春节、五一、暑期、中秋、国庆 | 消费出行、真实区域业务，核当年休市日 | 预订销售/利润或具体政策增量，板块承接 | 到节日相关股必涨；团圆寓意等于业绩 |
| 两会、经济政策会议、地方政策 | 正式议程、预算、支持对象 | 政策变成可执行资金、项目或订单 | 热词、旧政策回顾当新增催化 |
| 财报、业绩预告与修正 | 预约日期、事前预期、扣非与现金流 | 可持续的利润改善，股价没有过度提前反映 | 同比高增长自动等于超预期 |
| 产业大会、新品与海外龙头财报 | 已核实供应链及资本开支 | 实际量产、订单和利润传导 | 展示原型、认证等于批量订单 |
| 涨价、库存与季节需求 | 产品/原料价差、产销和供给 | 毛利与真实成交、利用率共同改善 | 上游涨价利好所有上下游公司 |
| 利率、汇率及经济数据 | 官方时点，国内外敞口 | 相对原预期变化及公司净影响 | 贬值利好所有出口股、降息必涨 |
| 指数调样、ETF申赎 | 公告/生效日、原生份额与权重 | 可追溯需求与实际承接 | ETF成交额=净流入；调入必涨 |
| 解禁减持、回购增持、分红重组 | 计划、执行、完成分阶段 | 实际供求、现金流与估值变化 | 计划金额=成交；除息凭空赚钱 |
| 交割、月季末、长假前后 | 对应合约和资金占用 | 当期价差、流动性及持仓迁移证据 | 交割日一定跌、节后一定涨 |
| 冰点修复、突破与回踩 | 固定观察池、广度、压力和承接 | 新事件、新量价确认及原Skill资格 | 跌多了必涨、后排没涨就必补涨 |

## 执行要点

1. 日历只决定什么时候开始研究，事件只提供方向，量价与原Skill共同约束是否参与。
2. 默认前瞻20个交易日，事件后复核1—5个交易日；不是最佳买入日或强制持有期。
3. 板块相对收益、MA20广度与改善、成交额扩散、个股近期涨幅和最近压力分开看；提示参数未经收益验证。
4. 未加速试盘形态接潜伏V3.4，首板/守位接一触即发，连板回封接龙空龙，真实尾盘分钟接尾盘隔夜，筹码条件接三步选股。各自阈值、名次、退出不混用。
5. 官方文化交流活动不证明两岸股票每年中秋上涨，也不证明量化已买入；没有公司实益只能当短线主题观察。
6. 用首次公开时间对齐可交易时点，不能事后挑赢家。龙虎榜、ETF份额与资金分类不识别真实账户。

## 执行原文与来源

公开发行包：docs/playbooks/event-timing-skill/。其中SKILL.md为入口；references/event-catalog.md列出各类窗口，screening.md定义比较口径与五策略衔接，validation.md说明可交易样本检验，sources.md列官方查证链接和资料时效。
