# 尾盘隔夜战法

研究14:30后强势股的隔夜机会。七个指标不是七份独立盈利证据；规则通过不代表可以买到、次日会涨或已完成收益回测。不与龙空龙、一触即发、启动前潜伏混用参数。

## 执行

1. 先读[规则](references/rules.md)，采集/导入前读[数据契约](references/data.md)。使用上海时区和核验的交易日历。输入接受分析时点、候选范围、行情文件及用户确认的买入记录。
2. 未给范围先取得主板行情初筛，再为数值初筛项补历史、分钟、行业证据。所在工作台提供 late_day_research.py 按需采集、导入和发布，调用本技能唯一引擎。工作台不在当前环境时用 scripts/run.py --input 核验后的JSON --phase auto。不要猜工作台绝对路径。
3. 通过 scripts/engine.py 计算。verified 标志必须有来源核验，不能为通过条件填 true。公共采集器的原始材料不等于完成证券状态、历史涨停或分钟标签审核。空池有效，不为选出股票放宽阈值。
4. 展示七项条件、三类否决、源时间、实际覆盖、触板日期、VWAP比例、缺口和退出情景。最多5只，按同刻成交额降序、代码升序；不是收益排名。完整结果私有留档。
5. 没有持仓只给退出情景。确认买入后冻结入场前30分钟最低价，次日风险退出不受14:30限制，10:00结束本轮隔夜计划。未获得成交确认不得称已卖出。

14:30以前只预观察，14:57起停止新增。盘中源行情延迟≤90秒，最终判断报价跨度≤60秒。过期只能历史展示，收盘后不能用全天数据倒推尾盘可买。

## 边界

- 不下单、不设个人仓位、不新增定时任务或持续扫描服务；每次调用只做本次研究。10:00退出是纪律，不承诺无人调用也能自动通知。
- 无暗盘或主力净额证据不编造资金身份，不拿量比/VWAP/经营现金流代替主力资金。
- 阈值是可调研究初值，修改须保留版本，不能宣称已验证最优。
- 工作台存在时同步“我的策略”和“时点报告”，不增加入口或自动加入龙空龙监测。纯行情只留本地，通用代码规则才提交。
