# 用户授权的14:00初筛与14:20精筛

本流程仅在用户明确要求定时研究后由现有调度工具启用。调度时区为Asia/Shanghai，每天14:00、14:20触发；先查交易所日历，休市跳过，日历未知报告故障。它不授权自动交易，也不包含次日10:00自动提醒。电脑、网络和Codex须可用，触发时间不是保证完成时间。

两个阶段均为预观察。原14:30≤t<14:57的新增参与窗口、七项阈值、三类否决和退出规则保持不变；不能因为用户自行操作就把缺失证据改成通过。任何后续操作须由用户决定；14:30后需重新取得行情核验。

## 本次定时范围：热点前五、板内原始前三

- 只从工作台热点竞价模块的**前五热门板块、各板块原始前三名**取初始范围，再应用尾盘全部条件；不是先筛尾盘股票再把剩下的重排成前三。第一至第三名失败时不补第四名，板块不足五个也不扩围。
- 使用`research_modules.load_module('hot', now=实际分析时点)`读取已核验榜单；必要时先通过原热点研究入口刷新。核对`cutoff`为上一完整交易日、`next_session`为当天，原池日期与总数已核验。读取`sectors[].sector_rank`和`items[].sector_member_rank`，不得使用过滤后的数组下标重排名次。未执行、过期、更新失败或原始排名证据缺失时，暂停正式初筛并显示待验证，不从旧名单或全市场补齐。
- 现有热点榜比较范围是**上一交易日主板收盘涨停池**，不是全板块成分股排名，也不是当日实时涨幅前三。保留排名方法、范围、时点、来源和内容指纹；昨日原始排名与今日行业表现分开列示。只复用范围和原始排名，不导入龙空龙连板、第二次放量、竞价或回封资格。
- 14:00和14:20均核验该原始板块对应的固定东财行业仍上涨（涨幅>0），归属、行业报价自身时间与口径须可追溯，沿用90秒时效与60秒同刻要求。走弱移出正式候选，缺证据只待验证；不能更换上涨概念规避。不把“昨日热门且今日上涨”称为已证明今日仍全市场前五。
- 14:00冻结原始板块与名次，14:20不因新热点、新排名补入新股，也不重写初筛来源。精筛保留当时热度变化、淘汰原因及完整样本。此范围限制用于本次定时流程；旧版全市场复盘保留原版本和覆盖，不重新标成已按新范围执行。

## 14:00：冻结初筛名单

1. 先核验上述热点范围，冻结前五板块原始前三的交集代码，再以明确的非空`codes`在工作台运行按需采集与`preview`研究。原榜有效但无席位时直接记录成功空池，不传空代码触发默认全市场扫描。剔除已知ST、退市、停牌、特殊限制；证券状态未知另标。以涨幅、量比、换手与总市值的原区间进行数值初筛，补查前20日触板、分钟VWAP及市场/行业条件。公共采集原文不等于已完成验证，不得只为出名单写入`verified=true`。
2. 保存所有数值初筛项，不截断为十只。报告实际扫描范围、初筛数量、有效空池、接口失败和关键缺口。供应商字段仅能用于有标签的暂定初筛，精筛必须按数据契约复核。
3. 使用工作台`research_store.py`的私有路径、更新锁和原子写入，在`research/late_day/scheduled/YYYY-MM-DD/1400.json`冻结本次记录：`schema_version=1`、`trade_date`、`planned_slot="14:00"`、实际`as_of/generated_at`、`rule_hash`、`status`（complete/partial/failed）、`codes`、各股来源时点、原始证据引用、覆盖、缺口，以及整个记录的指纹。另存完整热点来源快照、来源指纹、原始板块/板内名次与当日行业证据。指纹按去除指纹字段后的内容计算。
4. 同日重试先读取已存在记录，不移动首次有效初筛的名单或压力参考。失败记录可以在14:20前以真实新数据重试，但保留失败档案；成功快照不能静默改写。尽快保存初筛，后续耗时补证另外留档，避免精筛时没有基线。
5. 更新尾盘页面并给出初筛完成、有效空池或数据不足的简报。不声称已完成14:30参与资格判断。

## 14:20：只精筛当日初筛名单

- 读取并核验当日1400快照与指纹，确认没有未来记录。名单、日期或证据链缺失时报告“初筛缺失/未完成”，不能沿用昨日名单或临时全市场补筛。
- `codes`为空且初筛成功时，精筛为有效空池；不要把空的`--codes`参数传成默认全市场扫描。初筛失败不等于成功空池。
- 仅对冻结名单重新取得价格、累计成交量额、换手、证券资格、行业和完整分钟证据，保留14:00与本次实际行情时点。逐项复核除参与时间之外的原门槛与否决。新失败项移入淘汰，缺证据项另列待验证，不因上次通过继续授予资格。
- 以14:00已知资料冻结本股最近有效压力及来源时点；包括当时日内高点和历史K线可核实压力，不能忽略更近压力或以14:20后的高点倒填14:00。没有可靠压力证据时，不声称已经确认突破。
- 14:20相对14:00的增量量额需来自同口径两帧，非负且单位一致；与历史比较时必须同一时间窗口。有增量只能说明这段时间的成交，不将它套入全日累计量比2—5的门槛，也不解释为已知主力净流入。

## 突破潜质观察顺序

先筛资格，再作人工证据排序；不编造概率、胜率或未经校验的综合分。这里的“前十名”是本次已覆盖、非时间条件已核验候选中的观察优先顺序，不是全市场预期收益前十。

依次比较以下证据，冲突或同档时说明取舍：

1. **结构**：对冻结的最近压力，已见放量越过且回踩承接，优先于只有接近压力、尚未确认突破；单笔拉升不视为持续突破。不能以更高涨幅自动排第一。
2. **承接**：分钟VWAP站稳比例、最近30分钟完整表现、14:00至复核时的回撤与承接；不奖励追离均价更远。
3. **相对强度**：同刻相对固定所属行业及沪深300的表现、行业支持是否持续；不换强势概念替代弱行业。
4. **成交与风险**：增量量价是否配合结构、有无滞涨或触板失败、最近压力与风险参考是否清楚。量比和换手更大并不自动更好。

只将非时间门槛、否决及上述排序所需关键证据齐全的项目列入正式观察前十。最多10只，不足不补位；必要资料不足时可以不给排名，单列待验证项并解释具体缺口。保留名单外和十名之后的完整记录，避免次日只展示上涨样本。

每个排名项说明代码名称、所属行业、热点板块原始名次与板内原始名次、排名范围与时点、当日行业涨幅及其源时间、14:00与本次价格/涨幅/量比/换手/市值、VWAP证据、冻结压力、突破或回踩事实、列此顺位的理由、仍需确认的条件、失效风险。没有持仓记录时不认定买入、盈利或已卖出。

## 发布和异常

- 每阶段用实际时点生成标准`preview`报告并通过`late_day_research.publish_report()`发布；不修改引擎阈值，不调用持仓冻结来伪造研究仓位。
- 精筛将观察前十代码按顺序写入报告的`preview_order`，对应行附`observation_rank`（1—10）、`breakout_reason`、`confirmation`、`risk`。这些是研究解释，`qualified_count`与`historical_pass_count`保持0，`research_passed/eligible`不得因此变成true。其余行仍完整保存和展示。
- 排名行另附`hot_leader`：`verified=true`仅在完整原始榜单核验后设置；字段为`sector`、`sector_rank`（1—5）、`member_rank`（1—3）、`ranking_as_of`、`target_session`、`scope`、`source`、`fingerprint`（原始榜单SHA256），以及`heat_verified`、`heat_pct`、`heat_time`、`heat_source`。板块和名次从14:00冻结基线复制，热度字段来自本次真实同刻行业证据，不能用采样时间替代源时间。网页只展示白名单字段，原文在私有证据中核验。
- 保存`research/late_day/scheduled/YYYY-MM-DD/1420.json`，包含初筛指纹、实际复核时点、标准报告、全部排名/淘汰/缺口与来源，并更新独立尾盘页面。纯研究数据不提交Git。
- 若唤醒延迟，注明原计划时点与真实采样时点，不能倒填行情。已错过初筛且无快照时，精筛报告缺失；收盘后到达的任务只报告错过或复盘，不冒充实时结果。重试沿用同一证据链，避免重复发布同一结论。
- 每个交易日有效阶段完成后给简明结论：初筛数量，或前十及理由，或有效空池/缺证据；相同运行的重复唤醒、休市与未变化且不需处理的状态保持安静。首次故障和恢复各报告一次。
