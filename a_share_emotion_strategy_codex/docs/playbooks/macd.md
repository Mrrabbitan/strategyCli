# MACD完成日线参照 v1.0.0

本次采用常用12/26/9口径，不声称找到了用户既有的自定义MACD参数或一套已验证收益系统。

DIF=EMA12−EMA26，DEA=EMA9(DIF)，柱值=2×(DIF−DEA)，EMA由第一根收盘初始化。使用同截面前复权、至少130根真实完成日K；不以盘中临时金叉代替完成日线。软件初始化历史不同，临界交叉要复核。

零轴上DIF≥DEA且柱值>0支持动能；柱递增只作增强，零轴下金叉只是恢复线索。MACD来自价格，不证明真实资金净流入，也不能单独定买卖。主线或价格结构失效时不等死叉。

计算内核由补涨龙Skill的scripts/analyze.py提供；指标、价格突破和量能分别展示，不累加成概率，不借用已暂停策略资格。参数为可调研究默认值，没有收益回测。
