# 工作台执行说明

本项目负责研究与呈现，不负责账户管理或自动交易。执行时遵守项目 [AGENTS.md](AGENTS.md)，使用私有存储接口，不把个人研究写进公开源码。

## 回答相关提问后的更新

1. 核对本轮问题涉及热点、龙空龙、策略规则或专题中的哪一部分，沿用用户已经确认的范围。
2. 按分析时点取数，分清事实、推断、策略假设与未取得的数据。今天没有交易时，只复盘最近完整交易日。
3. 对照原快照：名单、排序、介入或退出条件、风险、有效期、来源及数据质量的变化属于实质变化。仅查询次数和生成时间变化不算。
4. 热点或龙空龙任一模块发生实质变化，就保存对应私有快照；保留来源日期与旧版记录。不要因为另外一个模块未变化而跳过更新。
5. 运行 `python3 build_investment_site.py`，核对新内容、过期提示、页面入口和来源链接。日期可省略，不要求生成新的交易日报。
6. 只有数据变化时到此为止，不提交 Git。若修改了代码或规则，先运行相关测试，再逐个审查公开文件，提交并推送指定分支；不得把实际快照一起提交。

## 五时点报告

| 时点 | 研究重点 |
| --- | --- |
| 09:00 | 交易日、上一完整交易日量价、隔夜公开信息、当天待验证条件；不冒充最终竞价 |
| 10:30 | 已发生的竞价和盘中量价、高标反馈、板块联动及失效条件 |
| 13:30 | 午后延续、回流或走弱的证据，以及观察顺序变化 |
| 14:30 | 当日风险、隔夜条件和下一交易日需要验证的事项 |
| 19:00 | 完整复盘、量能计数、已披露资料与次日观察框架 |

常用入口：

```sh
python3 run_report.py --slot auto
python3 run_report.py --slot 10_30 --candidate-only
```

第一条生成真实研究并写入私有报告目录；第二条只提供候选研究队列，不生成报告或交易状态。人工核验催化证据时使用程序现有 `--emotion-evidence` 接口，不从新闻标题编造依据。情绪研究的催化要求不能套用成龙空龙新闻加分。

生产运行不得用 `--allow-stale`让旧行情通过。该选项仅用于明确标记的历史诊断，不能据此更新最新页面或生成当前参与信号。

报告保存自身 HTML 和 JSON，不再生成账户 `portfolio.json`，也不导入券商截图。板块资金中的公共 ETF 和北向持仓变化属于市场数据，须注明低频、延迟和估算口径。

## 时点页的实时部分

实时展示只在当前电脑运行，复用现有板块监控服务。页面由 `dashboard_server.py`提供；启动、停止或刷新网页不改变监控范围、阈值、通知偏好或去重状态。

- 只展示分析截止时点前已经记录的事件，历史日报不接收后来的行情。
- 保留行情时间、事件窗口、方向、来源和覆盖信息，不用网页读取时间替代行情时间。
- 无新增事件、覆盖不足、服务过期、休市和故障恢复分别显示；未知不写成“没有异动”。
- 同一事件重复读取不重复计数，不因重建页面重复推送。
- 不读取或返回私有通知配置、账户数据；不从 API 接受任意路径或命令。

议息等专题位于时点报告，保留独立日期和证据，不混入龙空龙候选资格。

## 完成前检查

- 四入口为热点、龙空龙、我的策略、时点报告；已删除的账户和 ETF 页面没有残留导航或隐藏数据。
- 三套策略的来源、版本与适用条件各自独立，缺数据不补位。
- 当前研究与历史报告日期分别显示；行情过期时明确停止当前信号。
- 真实持仓不被改写，研究状态不等于已成交，普通 A 股 T+1 与成交限制保留。
- Git暂存内容只有批准的项目代码、规则和人工示例，没有父仓库其他改动或实际研究产物。
